# Mohammad Iliyas — Portfolio

Responsive static portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` — main portfolio
- `style.css` — responsive styling and light/dark themes
- `script.js` — theme toggle, mobile navigation, scroll progress and reveal animations
- `resume.pdf` — resume download

## Hosting
GitHub Actions deploys the static site to GitHub Pages when changes are pushed to `main`.

Expected URL: https://mohammadiliyas.github.io/iliyas/
